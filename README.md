## ✨ Sobre

Site de página única (SPA) construído do zero com **React + TypeScript**, sem frameworks de UI — todo o visual (tema escuro, glows, animações) é CSS próprio. O foco foi caprichar nos detalhes de interação: textos digitados letra a letra, um cartão de foto que "vira" e revela um editor de código, formulário de contato funcional e navegação suave entre seções.

## 🧩 Seções

| Seção | O que tem |
|---|---|
| **Hero** | Apresentação com efeito de digitação e atalhos rápidos (GitHub, LinkedIn, contato, download do currículo) |
| **Projetos** | Cards com imagem, stack utilizada e links pro repositório/site no ar |
| **Sobre mim** | Bio + cartão de foto com flip 3D — clique ou passe o mouse pra revelar uma "janela de código" no verso |
| **Stack** | Tecnologias por Frontend / Backend / Ferramentas, com certificados em destaque |
| **Contato** | Formulário que envia e-mail direto (via Web3Forms), sem precisar de backend próprio |

## 📁 Estrutura

```
src/
├─ assets/            # imagens, currículo, certificados
├─ components/        # componentes reutilizáveis (Navbar, FlipCard, ProjectCard, ...)
└─ pages/Home/
   └─ sections/       # Hero, Projects, About, Stack, Contact
```

## 🚀 Rodando localmente

```bash
git clone https://github.com/CaioScura/my-portfolio.git
cd my-portfolio
npm install
```

Crie um `.env.local` na raiz (veja `.env.example`) com a chave do Web3Forms, necessária pro formulário de contato:

```
VITE_WEB3FORMS_ACCESS_KEY=sua_chave_aqui
```

```bash
npm run dev       # ambiente de desenvolvimento
npm run build     # build de produção
npm run preview   # pré-visualiza o build
```
